# Coherent Desktop 0.1.12

Исправлена остановка вертикальной прокрутки настроек, когда указатель находится над таблицей процессов Coherent. Таблица теперь передаёт вертикальное колесо мыши или жест тачпада внешней области настроек. Горизонтальная прокрутка широкой таблицы сохранена; запрет смещения всего интерфейса при прокрутке остаётся в силе.

На отдельном тестовом экране с CSS приложения проверены прокрутка вниз и вверх над строками и горизонтальная прокрутка таблицы. Проверены сборка и публичный подписанный канал обновлений.

Обновление и перезапуск установленного клиента на ПК владельца для этой версии не выполнялись по его просьбе: переход с 0.1.11 он проверит самостоятельно через приложение.
