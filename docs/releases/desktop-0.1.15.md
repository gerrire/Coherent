# Coherent Desktop 0.1.15

- Чат обновлён по согласованному макету. Отступ от списка бесед составляет 16 px при любой ширине обычного окна.
- Имя, статус и кнопки звонка собраны в одной шапке. Сведения о беседе открываются нажатием на имя.
- Сообщения одного автора сгруппированы. Время указано рядом с сообщением, а последние реплики примыкают к полю ввода.
- Шрифты входят в сборку и загружаются локально.
