# Coherent 0.1.4

- Облачная переписка без Recovery Key и подтверждения устройства. История новых сообщений доступна после обычного входа в браузере и Windows; сервер шифрует содержимое при хранении.
- Звонки сохраняют E2EE LiveKit/OpenMLS и сверку по эмодзи. Одноразовые ключи создаются перед звонком и живут только в памяти, без настройки аккаунта и сохранения 12 слов.
- Доступ к ключевым операциям звонка привязан к участнику, звонку и подключившей его сессии. После выхода новое подключение создаёт независимый ключ.
- Аккаунты, друзья, беседы, группы, сообщества, настройки и управление сессиями сохраняются. Сброс старых сообщений на сервере выполняется отдельным действием владельца; установка приложения сама историю не удаляет.
- Честные обозначения облачного шифрования, обновлённая админка и документация.

Подписывается прежним ключом обновлений. Старый Windows-клиент нужно обновить для нового протокола звонков. Работа с оборудованием конкретного Windows-ПК требует проверки на устройстве.
