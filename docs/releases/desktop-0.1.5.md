# Coherent 0.1.5

- Исправлена утечка обработчиков при переподключении событий. Каждое подключение имеет собственные обработчики и идентификатор; очистка старого подключения не отключает новое.
- Ограничены очереди системного звука до воспроизведения, размеры сетевых ответов и объём истории на экране. Ранние сообщения остаются на сервере и загружаются страницами.
- Изображения вне области просмотра и в скрытом окне освобождаются из памяти. Скрытое окно без звонка использует экономный режим WebView2; отключены принудительные флаги фоновой активности.
- Исправлен запуск обработки микрофона при приостановленном AudioContext. При сбое дополнительной обработки сохраняется исходный звук, при пропавшем сохранённом USB-устройстве проверяется системный вход. Разрешения Windows сохраняют приоритет.
- В настройках звука добавлена проверка уровня микрофона. При наличии активного входа звонка проверяется его звуковая дорожка; иначе временный захват автоматически останавливается через 20 секунд или при закрытии настроек.
- Свои сообщения можно редактировать и удалять для всех участников через меню «…». Изменения приходят в реальном времени. Удаление стирает содержимое и вложения; на месте остаётся отметка «Сообщение удалено».
- Добавлены ограниченные локальные журналы потребления памяти WebView2 без содержимого сообщений, звука и ключей.

Обновление подписывается прежним ключом. Аккаунты, переписка и настройки сохраняются. Сквозное шифрование звонков сохраняется.

Исправлены найденные причины накопления ресурсов; конкретный случай роста до 6–7 ГБ и работу Fifine необходимо подтвердить на Windows-ПК. Сборка на Windows runner не заменяет проверку оборудования и длительной работы в трее.
