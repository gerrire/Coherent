## Звонки и оформление

- Групповой звонок подключает звук по мере готовности участников.
- После выхода участника звонок продолжается с новым ключом. При обрыве сети клиент пробует переподключиться.
- В фиолетовой теме вернулся прежний градиент кнопки Coherent. Аватары снова используют градиенты выбранной темы.
