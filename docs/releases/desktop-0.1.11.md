# Coherent Desktop 0.1.11

Исправлено отдельное окно входящего звонка: оно больше не блокирует собственный запрос текущего пользователя, необходимый для проверки приглашения. Ошибка этого запроса ранее оставляла окно без данных звонящего и без возможности ответить, хотя главное окно могло принять тот же звонок.

В настольной карточке отображается знак Coherent вместо первой буквы служебного сообщения. Ошибка загрузки больше не представляется как подтверждённая недоступность звонка. Веб-карточка сохраняет прежний вид.

Проверены сборка интерфейса, регрессии карточки и приглашений, а также нативные проверки разрешённых запросов. Ответ на реальный входящий звонок через исправленное отдельное окно требует повторной проверки с другим устройством.

Это обновление не исправляет отображение WebView2 на вкладке «Процессы» Диспетчера задач. Идентичность MSIX и доверие к дополнительному сертификату не включаются. Существующий подписанный канал встроенных обновлений сохранён.
