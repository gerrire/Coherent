# Coherent Desktop 0.1.1

Обновления приложения получили отдельный блок в начале настроек: установленная и новая версии, прогресс скачивания, проверка подписи и кнопка «Установить и перезапустить». Во время звонка можно скачать пакет; установка доступна после завершения разговора. В Windows перезапуском управляет установщик обновления, без преждевременного запуска старого клиента.

Тестовые уведомления и проверки звука, захвата и кодирования перенесены в свёрнутый раздел «Диагностика и проверки». Обычные настройки содержат только повседневные параметры приложения.

Ветка исходников переименована в **windows-client**. README посвящён Windows-клиенту: скачивание, обновления, возможности и сборка. Инструкции по веб-интерфейсу и серверу вынесены отдельно.

Обновиться с 0.1.0 можно прямо в Coherent: **Настройки → Приложение → Обновления → Проверить → Установить**. В 0.1.1 следующие обновления используют отдельные шаги скачивания и установки. Вход и настройки сохраняются.
