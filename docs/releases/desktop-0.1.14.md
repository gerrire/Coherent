# Coherent Desktop 0.1.14

- Шапка беседы, история и поле ввода выровнены по общим краям. Текст сообщений крупнее, боковая панель компактнее.
- В списке друзей имена, статусы и кнопки стоят в отдельных колонках. В узких окнах действия с сообщением открываются через «⋯».
- Настройки открываются под заголовком Windows. Превью тем выровнены, числовые столбцы таблицы процессов прижаты к правому краю.

Оформление доработано по рекомендациям [Unslop](https://github.com/heydamir/unslop) Дамира Соколовского.
