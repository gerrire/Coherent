# Coherent Desktop 0.1.8

Входящий звонок больше не забирает фокус и не создаёт постоянно закреплённое поверх остальных приложений окно. При полноэкранной игре, скрытом или ограниченном курсоре и режиме занятости Windows отдельное окно не появляется. Проверка выполняется до создания дополнительного WebView и повторяется перед показом. Сам звонок остаётся доступен в Coherent; системные уведомления подчиняются настройкам Windows. Явное нажатие «Ответить» по-прежнему открывает клиент.

Полоса прокрутки списка бесед использует цвета выбранной темы, включая светлую. Одно исправление применяется в Windows и веб-версии.

Сообщённый сбой видеодрайвера на другом устройстве не воспроизведён; устранён найденный принудительный перехват фокуса. Проверки геометрии полноэкранных окон и ограничения курсора, тесты интерфейса и сборка выполняются перед публикацией. Обновление подписано прежним ключом и доступно через приложение. Обновление с перезапуском установленного клиента и проверка во время реальной игры не выполнялись.
