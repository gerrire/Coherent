# Coherent Desktop 0.1.7

Панель действий у сообщений приведена к актуальной веб-версии: быстрые кнопки ответа, редактирования и удаления появляются рядом с сообщением при наведении, а на сенсорном экране остаются доступными под ним. Перенесены соответствующие стили, цитирование и переход к исходному сообщению; добавлена передача ответа вместе с вложениями через нативный клиент. Старое меню через «…» удалено.

Остальные части интерфейса и поведение окон не менялись. Обновление доступно внутри приложения и подписывается прежним ключом.
