# Coherent Desktop 0.1.13

Входящий звонок появляется поверх обычных и безрамочных окон на мониторе активного приложения. Предпросмотр не забирает фокус. Он скрывается при переключении фокуса или через 10 секунд без взаимодействия, сохраняя приглашение в Coherent. Для эксклюзивного полноэкранного режима остаются системные уведомления.

При переходе с другого устройства доступна кнопка «Перенести звонок сюда». Сервер освобождает блокировку согласования ключей, оставленную старым устройством. Клиент показывает этап подключения и предлагает повторить попытку, если согласование зависло.

В Windows клиент запускает воспроизведение при подключении и пробует системный выход, если выбранные динамики недоступны. Карточка входящего звонка обновлена в обоих клиентах с использованием рекомендаций Unslop (Дамир Соколовский).

Проверка реального звонка между двумя устройствами и работа поверх конкретной игры требуют отдельного прогона.
