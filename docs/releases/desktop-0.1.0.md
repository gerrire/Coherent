# Coherent Desktop 0.1.0

Первый публичный выпуск Windows-клиента Coherent на Tauri 2 и Rust. Интерфейс упакован в приложение и сохраняет оформление веб-версии.

- Нативная демонстрация экрана или окна, выбор приложения и предпросмотр. Свёрнутые окна доступны в списке; служебные окна Windows скрыты.
- Захват звука компьютера с исключением воспроизведения Coherent. Удаление жёлтой рамки использует разрешение Windows.
- Настройки разрешения до 4K, частоты до 60 кадров/с и битрейта до 50 Мбит/с. VP8, H.264, VP9 и AV1 доступны по возможностям устройства; фактическое качество зависит от оборудования и сети.
- Настройки клиента, собственный заголовок окна, сворачивание в трей, окно входящего звонка и системные уведомления со звуком.
- Подписанные обновления внутри приложения. Установка обновления откладывается во время звонка.

Скачайте **Coherent-setup.exe** из файлов выпуска. Архитектура — Windows x64. Для передачи системного звука требуется Windows build 20348 или новее. Обновления подписаны ключом Coherent; сертификата издателя Windows (Authenticode) у этого установщика пока нет.

Приложение остаётся в разработке. Отдельная вкладка браузера пока не захватывается; выбирайте окно браузера. 4K/60 на всех устройствах и полный переход между двумя опубликованными выпусками ещё не подтверждены. Проверены передача через сервер с E2EE, захват экрана 2560×1440 около 25 кадров/с и изоляция принятого WebRTC-звука с сохранением внешнего звука.

Если установлена прежняя экспериментальная сборка с техническим номером 0.2.0, установите 0.1.0 вручную поверх неё. Вход и настройки сохраняются. Следующие обновления будут иметь номера 0.1.1, 0.1.2 и далее.
