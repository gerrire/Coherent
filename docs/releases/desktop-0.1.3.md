# Coherent 0.1.3

- Список сессий устройств в настройках профиля: время входа, последняя активность и завершение отдельной сессии. Отзывается её токен, закрывается подключение событий и завершается звонок, подключённый из этой сессии. Доверие к криптографическим ключам устройства этим действием не отзывается.
- Исправлены повторные подключения к звонку: позиция подтверждённых событий сохраняется при освобождении ключей звонка; ранее повреждённая локальная сессия восстанавливается через новую MLS-группу. Гонки одновременного обновления состава обрабатываются повторной синхронизацией.
- Кратковременный сетевой сбой при обновлении ключа не разрывает звонок сразу. Ошибки проверки ключей остаются блокирующими; длительный сбой предлагает повторное подключение.
- Демонстрацию можно открыть отдельно на весь экран из сетки и крупного плана. Сохраняются пропорции изображения, скрываются подписи и панели. Если браузер не предоставляет системный полноэкранный режим, используется всё окно приложения.
- В мобильном меню появилась явная кнопка закрытия. При открытии оформления меню бесед закрывается.
- Кнопка отправки больше не перемещается при получении фокуса на телефоне: первое нажатие отправляет сообщение.
- Во время активного звонка скрыты большая шапка собеседника и обычная подпись о шифровании переписки. Сообщения об ошибках безопасности остаются доступны.
- Исправлено сохранение очереди фото в WebKit: шифротекст хранится как байты, с чтением старого формата Blob. Ответы API не кешируются; состояние защищённой сессии проверяется перед обращением к её полям, сетевые запросы имеют ограничение ожидания.

Выпуск подписывается прежним ключом обновлений и доступен через настройки приложения. Сборка выполняется Windows runner. Физическая проверка камеры iPhone и оборудования Windows остаётся отдельной проверкой на устройствах.

Проверки перед публикацией: 35 backend, 31 frontend и 5 Rust; свежая миграция PostgreSQL до 0026 без расхождений моделей. В настоящих браузерах проверены три выхода и возврата в звонок, полноэкранное видео 16:10 через LiveKit и завершение сессии с отключением медиа. В WebKit с мобильным представлением проверены меню, выбор темы и отправка/чтение зашифрованного JPEG через интерфейс.
