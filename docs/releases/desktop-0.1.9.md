# Coherent Desktop 0.1.9

У списка бесед и истории чата теперь единое оформление прокрутки: в Chromium/WebView2 ползунок шириной 5 px, прозрачная дорожка, цвета текущей темы. Ползунок появляется при прокрутке, наведении или фокусе с клавиатуры; после прокрутки скрывается через 900 мс, если наведение/фокус больше не удерживают его видимым. Пространство под полосу постоянно, поэтому сообщения не сдвигаются при её появлении. В Firefox используется системная тонкая полоса, в режиме высокой контрастности — доступное системное оформление.

Обновления после автоматической проверки скачиваются и проверяются в фоне. Если проверка прошла во время звонка, автоматическое скачивание откладывается до его завершения. Установка запускается пользователем, с тихим установщиком и автоматическим возвратом в приложение. Вход и настройки сохраняются, последний открытый чат восстанавливается по идентификатору, отдельно для каждого аккаунта. При неотправленном тексте, вложениях или текущей отправке перезапуск блокируется; черновики не записываются открытым текстом на диск.

Замена исполняемого файла Windows по-прежнему требует завершения и перезапуска процесса. Непрерывный звонок через обновление не поддерживается: установка блокируется до окончания звонка. Автоматического перезапуска без нажатия кнопки нет.

Проверены ширина и совпадение цветов обеих полос в браузере для шести тем, тесты обновлений и восстановления открытой беседы, сборка Windows и публичный подписанный канал обновлений. Реальное обновление с перезапуском установленного клиента не проверялось.
