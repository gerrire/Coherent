# Coherent 0.1.2 — подготовка выпуска

- Текущая MLS-переписка и подтверждение устройств; сообщения и вложения совместимы с веб-клиентом этого выпуска.
- Смена ключа восстановления с сохранением старой истории и сбросом доверия другим устройствам.
- Отдельные MLS-группы для ключей звонков: сервер не выдаёт ключ медиа.
- Исправление переключения обработки микрофона, очереди файлов и отметок прочтения.
- Долгая загрузка файлов не удерживает общую блокировку остальных запросов Windows-клиента.
- Управление группами и серверами; настройки доступны с клавиатуры.

Windows собирается и проверяется на Windows runner. Для подписанного установщика нужен исходный ключ обновлений в GitHub Actions secrets `TAURI_SIGNING_PRIVATE_KEY` и его пароль, если он установлен. Публичный ключ установленного клиента менять нельзя.

Workflow `Windows client` проверяет приложение при изменениях. Ручной запуск с `prepare_release` из main создаёт подписанный **черновик** выпуска. Перед публикацией проверить на Windows вход, подтверждение со старого устройства, Recovery, переписку, микрофон, демонстрацию и обновление с 0.1.1. Подготовка черновика сама по себе не подтверждает эти пользовательские проверки.
