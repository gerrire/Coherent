# Coherent 0.1.2

- Текущая MLS-переписка и подтверждение устройств; сообщения и вложения совместимы с веб-клиентом этого выпуска.
- Смена ключа восстановления с сохранением старой истории и сбросом доверия другим устройствам.
- Отдельные MLS-группы для ключей звонков: сервер не выдаёт ключ медиа.
- Исправление переключения обработки микрофона, очереди файлов и отметок прочтения.
- Долгая загрузка файлов не удерживает общую блокировку остальных запросов Windows-клиента.
- Управление группами и серверами; настройки доступны с клавиатуры.

Windows-приложение собрано и проверено на Windows runner из исходников `55764b2cdd9d03cc09226161a4eb8e936372ea93`. Исходный ключ обновлений найден на ПК владельца. Готовый установщик подписан этим ключом с привязкой к версии 0.1.2; добавлен `latest.json` для обновления прямо из приложения. Публичный ключ прежний, поэтому пакет совместим с проверкой подписи в клиентах 0.1.0 и 0.1.1.

В выпуске: `Coherent-setup.exe`, `Coherent-setup.exe.sig`, `latest.json`, `SHA256SUMS.txt`. Подпись и версия проверены библиотекой Tauri; изменение байта установщика отвергнуто. Это та же сборка, которая ранее была опубликована без подписи для ручной установки; её исполняемый файл не менялся.

Обновление: **Настройки → Приложение → Проверить обновления → Скачать обновление → Установить и перезапустить**. Во время звонка пакет можно скачать, установка доступна после его завершения. Если 0.1.2 уже установлена вручную, повторное обновление на ту же версию не предлагается; следующий подписанный выпуск будет доступен обычным способом.

Новые MLS-сценарии, вход, подтверждение устройства, Recovery, микрофон, демонстрация и переход с 0.1.1 на физическом Windows-ПК ещё требуют проверки. Установщик в ходе восстановления подписи не запускался. Ранее подтверждён переход 0.1.0 → 0.1.1; его нельзя приравнивать к проверке этого выпуска.

Ключ и пароль добавлены в защищённые GitHub Actions secrets для следующих сборок. [Инструкция по подписи и расположение оригинала](../desktop-signing.md).
