## Звонки и оформление

- Групповой звонок подключает звук по мере готовности участников.
- При смене состава оставшиеся участники продолжают звонок с новым ключом. Временная рассинхронизация ключей запускает повторную сверку.
- При сетевом обрыве клиент пробует переподключиться. Перезагрузка в той же сессии позволяет вернуться в звонок автоматически.
- Вернули более яркие градиенты значку приложения и аватарам.
