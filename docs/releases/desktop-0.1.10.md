# Coherent Desktop 0.1.10

Исправлен запуск RNNoise в установленном Windows-клиенте: политика содержимого разрешает компиляцию встроенного WebAssembly, при этом выполнение строк JavaScript через eval остаётся запрещено. Ошибки подготовки обработки больше не оставляют опубликованную дорожку без звука. Микрофон использует отдельный звуковой контекст 48 кГц и один канал; при отказе шумоподавления клиент автоматически сохраняет передачу голоса с заданной громкостью. Проверка микрофона в настройках теперь проверяет обработанный звук через локальную передачу WebRTC, показывает вход и выход отдельно и не отправляет звук другим пользователям.

Окно входящего звонка закрывается после ответа, отказа или завершения приглашения именно для текущего пользователя. Закрытое окно освобождает свой WebView; устаревший сигнал закрытия не затрагивает новый звонок. Добавлена доступная кнопка закрытия, в том числе при ошибке подключения.

В настройках приложения отображается суммарная частная оперативная память всех принадлежащих Coherent процессов, выделенная память и загрузка процессора. Доступна таблица с назначением, именем и идентификатором каждого процесса и штатная диагностика WebView2. Посторонние процессы Node.js не учитываются. Windows 11 может по-прежнему показывать WebView2 отдельной группой в системном диспетчере задач; приложение не переименовывает процессы Microsoft и не отключает их изоляцию.

Проверены 42 теста интерфейса, 7 нативных тестов, сборка и подпись установщика, совпадение списка процессов с Windows и физический микрофон в установленном клиенте с RNNoise и локальным приёмом WebRTC. Повторный звонок с другим устройством и обновление с перезапуском через установленный клиент не проверялись; установка этой сборки на тестируемом ПК выполнена локальным установщиком. Встроенный подписанный канал обновлений сохранён.
