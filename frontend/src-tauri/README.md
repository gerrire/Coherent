# Coherent для Windows

Клиент собирается на Tauri 2. Интерфейс React/TypeScript из `frontend/src` упакован в установщик и работает локально в WebView2. Это не окно с открытым сайтом: сетевой API и WebSocket подключает Rust, а токен сессии шифруется Windows DPAPI и не передаётся JavaScript. Чаты, звонки, настройки устройств и интерфейс общие с веб-версией.

Экран и окна перечисляет и захватывает Windows Graphics Capture. Основной путь видео: BGRA → read-only WebView2 SharedBuffer → VideoFrame → canvas track → LiveKit/WebRTC с E2EE. Через события идут только размеры/идентификаторы и подтверждения. Превью ограничено 480×270 и остаётся JPEG. Для старого WebView2 без VideoFrame предусмотрен совместимый ограниченный путь 720p/15; локальные диагностические проверки также могут использовать JPEG. Это не путь основного потока на проверенном ПК.

Звук компьютера захватывает Windows Process Loopback. Исключается фактическое дерево воспроизведения главного WebView2, определённое через `BrowserProcessId`, вместо предположения, что все аудиопроцессы всегда принадлежат текущему Rust-процессу. Если определить процесс не удалось, захват звука не запускается; полного endpoint loopback в качестве обхода нет. Формат WASAPI явно преобразуется из float stereo 48 kHz в PCM16; отдельная дорожка публикуется через AudioWorklet и LiveKit. API требует Windows build 20348+. Отсутствие поддержки даёт ошибку звука, сохраняя видеозвонок. Обычный веб-клиент сохраняет ограничения браузера.

Буфер видео ограничен 3840×2160×4 байт; кадры большего размера уменьшаются до 4K. Одновременно передаётся один кадр, новый ждёт ACK после копирования VideoFrame. Это устраняет очередь тяжёлых кадров, но не является zero-copy или прямой передачей GPU-текстуры. Выбранные 15/30/60 FPS — целевой предел, а фактическая частота зависит от источника, кодировщика и сети. H.264 подтверждён реальным звонком; остальные кодеки выбираются по возможностям WebRTC и требуют отдельной проверки на целевых устройствах.

«Убрать жёлтую рамку» вызывает официальный `GraphicsCaptureAccess.RequestAccessAsync(Borderless)` и использует `WithoutBorder` только при разрешении Windows. Отказ не маскируется. Главная страница и окно входящего звонка имеют разные разрешения; окно звонка не может запускать захват, менять настройки устройств или устанавливать обновления.

## Сборка на этом ПК

Нужны Visual Studio с MSVC и Windows SDK, Rust MSVC, Node.js и WebView2. На текущем ПК всё необходимое уже подготовлено; портативный Node лежит в игнорируемой папке `.tools`.

Из корня репозитория:

```powershell
.\scripts\build-desktop.ps1
```

Установщик появится в `frontend/src-tauri/target/release/bundle/nsis/Coherent-setup.exe`, подпись — рядом в `.sig`. После успешной сборки скрипт удаляет прежние установщики и устаревший `latest.json` только из этой папки. Скрипт берёт локальный ключ подписи обновлений из `%USERPROFILE%\.tauri\coherent.key`, а пароль расшифровывает из `%USERPROFILE%\.tauri\coherent.key.password.dpapi`. Пароль защищён учётной записью Windows. **Сохрани резервную копию ключа и пароль в защищённом месте:** без них следующие версии не смогут обновить уже установленные приложения. Не добавляй приватный ключ или пароль в Git.

Для локальной разработки можно запустить `npm run tauri dev` из `frontend/`. По умолчанию установленный клиент подключается к `https://coherent-web.ru`. Для разработки с локальным API установи переменную `COHERENT_API_BASE_URL=http://127.0.0.1:8000` перед запуском клиента.

## Локальные проверки

`npm test` в `frontend` проверяет отмену старта, остановку во время публикации, устаревшие события, владение общей памятью, отмену доступа к устройствам и откладывание обновления во время звонка. `cargo test --release --lib --features tauri/custom-protocol` включает регрессию запуска аудиопомпы с потока без контекста Tokio. Полный сценарий требует двух аккаунтов и проверки удалённого изображения/звука; локальный self-check этого не заменяет.

`scripts/media-test-source.cs` — отдельное движущееся окно с синтетическим тоном для ручного E2E. Оно не входит в установщик. Диагностика находится в `%LOCALAPPDATA%\Coherent\diagnostics`, ограничена четырьмя файлами примерно по 2 MiB и не сохраняет кадры, PCM, API-токены и сообщения.

## Выпуски и обновления

Первый публичный Windows-выпуск — **0.1.0**; дальнейшие исправления выходят как 0.1.1, 0.1.2 и далее. Исходники Windows-клиента публикуются в отдельной ветке `codex/desktop-rebuild`. Надпись «Когерент в разработке» сохраняется. Номер 0.1.0 не означает обещание стабильного 1.0.

1. Обнови версию в `tauri.conf.json`, `Cargo.toml`, `Cargo.lock`, `frontend/package.json` и `frontend/package-lock.json`, затем собери подписанный установщик через `build-desktop.ps1`.
2. Выполни `.\scripts\prepare-desktop-release.ps1` из корня. Скрипт создаст `latest.json` рядом с установщиком и файлом `.sig`.
3. Создай обычный (не draft и не prerelease) GitHub Release с тегом `desktop-v<version>` в `gerrire/Coherent`. Прикрепи установщик и `latest.json`. Файл `.sig` можно также приложить для аудита; его содержимое уже встроено в `latest.json`.
4. Клиент проверяет `releases/latest/download/latest.json` при запуске и раз в шесть часов. Проверка и установка доступны в настройках приложения. Подпись проверяет Tauri Updater; установка откладывается при активном звонке, в том числе начавшемся во время скачивания.

Файл `latest.json` первого выпуска позволит проверять следующие версии. Обновление требует новой версии по SemVer, подписанной тем же ключом. GitHub `releases/latest` указывает на последний обычный выпуск; prerelease и draft не подходят.

Локальные экспериментальные сборки ранее имели технический номер 0.2.0. На таком ПК первый публичный пакет 0.1.0 нужно установить вручную поверх прежней копии: автоматическое обновление намеренно не понижает версию. После установки 0.1.0 следующие выпуски 0.1.x будут обновляться обычным способом. Идентификатор приложения и зашифрованный сеанс сохраняются.

Подпись Tauri защищает канал обновления. Она не является сертификатом издателя Windows: для устранения предупреждения SmartScreen при первом запуске потребуется отдельная подпись Authenticode.
