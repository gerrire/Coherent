# Coherent для Windows

Клиент для личных и групповых чатов, голосовых и видеозвонков и демонстрации экрана. Интерфейс работает локально; захват экрана, системный звук, трей и обновления используют возможности Windows.

## Скачать

**Текущий выпуск — 0.1.1.** [Скачать Coherent-setup.exe](https://github.com/gerrire/Coherent/releases/latest/download/Coherent-setup.exe) · [Все выпуски и изменения](https://github.com/gerrire/Coherent/releases).

Запустите установщик и войдите в свой аккаунт Coherent. Повторная установка сохраняет вход и настройки. Клиент подключается к [coherent-web.ru](https://coherent-web.ru/).

Нужны Windows x64 и Microsoft Edge WebView2. Для захвата звука компьютера требуется Windows build 20348 или новее. Проект находится в разработке.

## Обновление внутри приложения

Откройте **Настройки → Приложение → Обновления приложения**.

1. Нажмите «Проверить обновления». Новые версии также проверяются автоматически при запуске и каждые шесть часов.
2. Нажмите «Скачать обновление». Клиент показывает прогресс и проверяет подпись пакета.
3. Нажмите «Установить и перезапустить». Coherent обновится и откроется снова с сохранённым входом.

Скачать обновление можно во время звонка; установка доступна после его завершения. Открывать браузер и искать установщик для обычного обновления не требуется. Версии исправлений идут по порядку: 0.1.0 → 0.1.1 → 0.1.2 и далее.

## Возможности клиента

- Личные и групповые сообщения, вложения, звонки с камерой и сквозным шифрованием медиа.
- Нативный захват экрана и окна, выбор программы и предпросмотр. Системный звук передаётся с исключением воспроизведения Coherent.
- Настройки демонстрации до 4K, 60 кадров/с и 50 Мбит/с; VP8, H.264, VP9 и AV1 по возможностям устройства. Это верхние пределы, а фактическая передача зависит от источника, оборудования и сети.
- Темы оформления, выбор устройств, индивидуальная громкость собеседников и демонстраций.
- Сворачивание в трей, окно входящего звонка и уведомления Windows.

Проверки звука и захвата скрыты в свёрнутом разделе **«Диагностика и проверки»** внизу настроек приложения. Они не запускаются автоматически.

## Разработка Windows-клиента

Исходники этой ветки: **[windows-client](https://github.com/gerrire/Coherent/tree/windows-client)**. Интерфейс — React и TypeScript, оболочка — Tauri 2 и Rust, захват звука — небольшой модуль C++/WASAPI.

Для разработки нужны Node.js 20.19+, Rust MSVC и Visual Studio с компонентами C++ и Windows SDK:

```powershell
cd frontend
npm ci
npm run tauri dev
```

Подписанный пакет собирается локально из корня проекта:

```powershell
.\scripts\build-desktop.ps1
```

Ключ подписи хранится отдельно от репозитория. Подробности: [сборка и устройство клиента](frontend/src-tauri/README.md), [проверки и ограничения](docs/desktop-stabilization.md), [изменения 0.1.1](docs/releases/desktop-0.1.1.md).

Веб-интерфейс и серверная часть описаны в [инструкции разработчика](docs/web-development.md) и [схеме развёртывания](docs/deployment.md).
