# Когерент · Coherent

Мессенджер для личного общения, групповых бесед и сообществ: сообщения, звонки и демонстрация экрана в браузере и приложении для Windows. Проект находится в разработке.

**[Открыть веб-версию](https://coherent-web.ru/)** · **[Скачать для Windows](https://github.com/gerrire/Coherent/releases/download/desktop-v0.1.2-manual/Coherent_0.1.2_x64-setup.exe)** · **[Все выпуски](https://github.com/gerrire/Coherent/releases)**

## Возможности

- Личные и групповые переписки, вложения, друзья, уведомления и история сообщений.
- Голосовые и видеозвонки, показ экрана, выбор устройств и настройки звука. Для звонков используется LiveKit.
- Сообщества с текстовыми каналами, ролями и управлением участниками. Голосовые каналы сообществ и персональные права отдельных каналов ещё разрабатываются.
- Темы оформления, адаптивный веб-интерфейс и приложение Windows с системными уведомлениями и треем.
- Вложения хранятся до трёх дней; общий объём вложений на сервере ограничен 15 ГиБ. После удаления файла сообщение остаётся в беседе.

## Защита переписки

Личные и групповые беседы используют сквозное шифрование на основе MLS после настройки ключей участниками. Вложения в таких беседах шифруются на устройстве. Текстовые каналы сообществ используют серверное шифрование. Старая история, созданная до перехода на E2EE, отображается как облачная до её переноса.

Для подключения нового устройства можно использовать подтверждение с доверенного устройства. Запасной способ восстановления доступа к зашифрованной истории — Recovery Key из 12 слов. Сохраните его в надёжном месте: если потерять все доверенные устройства и ключ, восстановить старую E2EE-переписку не получится. Ключ не отправляется по почте.

Шифрование не скрывает от сервиса все метаданные, например состав бесед. Интеграция шифрования Coherent пока не проходила независимый аудит. Подробности и границы защиты: [архитектура безопасности](docs/security-mls.md).

## Приложение для Windows

Нужны Windows x64 и Microsoft Edge WebView2. Скачайте [установщик 0.1.2](https://github.com/gerrire/Coherent/releases/tag/desktop-v0.1.2-manual) и запустите его. Сборка подготовлена в GitHub Actions; установку и работу устройств на физическом ПК с Windows ещё необходимо проверить.

Версия 0.1.2 пока устанавливается вручную. Встроенное автоматическое обновление проверяет подпись; для выпуска, совместимого с ранее установленными клиентами, нужен исходный приватный ключ подписи обновлений. Для передачи системного звука при демонстрации экрана требуется Windows build 20348 или новее. [Устройство и сборка Windows-клиента](frontend/src-tauri/README.md).

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| `frontend/` | Веб-интерфейс на React и TypeScript, приложение Tauri для Windows |
| `backend/` | API на Python и FastAPI, модели PostgreSQL и миграции Alembic |
| `crates/coherent-crypto/` | Общее криптографическое ядро на Rust и OpenMLS |
| `deploy/` | Конфигурация развёртывания, резервных копий и сопровождения |
| `docs/` | Архитектура, развёртывание и описание изменений |
| `.github/workflows/` | Проверки, сборки Windows и подготовка образов для сервера |

Основная ветка — `main`. Она содержит веб-клиент, сервер и исходники Windows-приложения. При успешной сборке основная ветка используется для автоматической выкладки сервера.
