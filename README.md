# Когерент · Coherent

Мессенджер для личного общения, групповых бесед и сообществ: сообщения, звонки и демонстрация экрана в браузере и приложении для Windows. Проект находится в разработке.

**[Открыть веб-версию](https://coherent-web.ru/)** · **[Скачать для Windows](https://github.com/gerrire/Coherent/releases/download/desktop-v0.1.4/Coherent-setup.exe)** · **[Все выпуски](https://github.com/gerrire/Coherent/releases)**

## Возможности

- Личные и групповые переписки, вложения, друзья, уведомления и история сообщений.
- Голосовые и видеозвонки, показ экрана, выбор устройств и настройки звука. Для звонков используется LiveKit.
- Сообщества с текстовыми каналами, ролями и управлением участниками. Голосовые каналы сообществ и персональные права отдельных каналов ещё разрабатываются.
- Темы оформления, адаптивный веб-интерфейс и приложение Windows с системными уведомлениями и треем.
- Вложения хранятся до трёх дней; общий объём вложений на сервере ограничен 15 ГиБ. После удаления файла сообщение остаётся в беседе.

## Защита общения

Личные и групповые сообщения, текстовые каналы и вложения используют серверное AES-256-GCM. Мастер-ключ хранится отдельно от PostgreSQL; API расшифровывает данные только для авторизованных участников. История доступна после обычного входа с другого устройства. Это облачное шифрование, сервер имеет доступ к содержимому. Recovery Key и подтверждение криптоустройства для переписки не требуются.

Звонки сохраняют сквозное шифрование LiveKit: общий ключ медиа выводится устройствами через MLS. Одноразовые ключи создаются перед звонком, хранятся в памяти и освобождаются при выходе. API хранит публичные ключи и непрозрачные сообщения протокола. Для проверки участников можно сравнить эмодзи и код в звонке. При первоначальном обмене публичными ключами используется доверие к авторизованному серверному каталогу; без независимой сверки первоначальная подмена не исключена.

Прежняя E2EE-история на действующем сервере сбрасывается отдельной командой владельца после проверки резервной копии. Обновление схемы само историю не удаляет. Криптографическое ядро и адаптеры сохранены для звонков и возможного будущего E2EE текста. Подробности: [модель безопасности](docs/security-model.md), [переход и откат](docs/cloud-transition.md).

## Приложение для Windows

Нужны Windows x64 и Microsoft Edge WebView2. Скачайте [установщик 0.1.4](https://github.com/gerrire/Coherent/releases/tag/desktop-v0.1.4) или обновитесь из настроек установленного Coherent. Сборка подготовлена в GitHub Actions и подписана исходным ключом обновлений; работу новых функций и устройств на физическом ПК с Windows ещё необходимо проверить.

Версия 0.1.4 поддерживает встроенное обновление с предыдущих публичных версий. Исходный ключ доступен сборкам через GitHub Actions secrets; [расположение локального ключа и настройка подписи](docs/desktop-signing.md). Для передачи системного звука при демонстрации экрана требуется Windows build 20348 или новее. [Устройство и сборка Windows-клиента](frontend/src-tauri/README.md).

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| `frontend/` | Веб-интерфейс на React и TypeScript, приложение Tauri для Windows |
| `backend/` | API на Python и FastAPI, модели PostgreSQL и миграции Alembic |
| `crates/coherent-crypto/` | Общее криптографическое ядро на Rust и OpenMLS |
| `deploy/` | Конфигурация развёртывания, резервных копий и сопровождения |
| `docs/` | Архитектура, развёртывание и описание изменений |
| `.github/workflows/` | Проверки, сборки Windows и подготовка образов для сервера |

Основная ветка — `main`. Она содержит веб-клиент, сервер и исходники Windows-приложения. При успешной сборке основная ветка используется для автоматической выкладки сервера.
